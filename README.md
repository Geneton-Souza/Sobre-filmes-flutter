# Sobrefilmes
Aplicativo para encontrar filmes de forma prática e intuitiva.

## Funcionalidades
- 🌟 **Lista de filmes populares**: Descubra o que está bombando no momento.
- 🔍 **Busca de filmes**: Encontre rapidamente o filme que procura.
- 🎬 **Lançamentos**: Mantenha-se atualizado com os novos filmes.
- 📝 **Descrição detalhada**: Toque no card do filme para ver mais informações.

## Como obter dados?
Os dados são fornecidos pela API TMDB. Para utilizar a API, siga os passos abaixo:
1. Cadastre-se no site: [The Movie Database (TMDB)](https://www.themoviedb.org/signup).
2. Confirme seu cadastro.
3. Acesse as configurações da sua conta no site.
4. No menu de configurações, clique em **API** e depois em **Solicitar chave de API**.
5. Preencha o formulário e copie sua chave.
6. Adicione a chave ao seu projeto utilizando o campo `apiKey`.

## Dependências
- **HTTP**: Responsável por requisições à API.
